## 本地保存与影响边界

1. `clone/fetch` 是下载；保存文件和 `git commit` 是本地操作。它们不会更新 GitHub 共享分支。新目录使用独立 `.git`，原项目文件不会因为在新目录编辑而改变。
2. 新目录的 `origin` 下载地址保留；推送地址设为 `disabled://local-only`，另设 `push.default=nothing`，阻止常规误推送。它不防止主动绕过配置、改用其他 URL 或通过网页/API 写入。将来确需推送时先明确分支与范围，再恢复推送配置。
