# EvalDock Mac App

桌面客户端、主界面、客户端契约测试和安装包构建已迁移至 [EvalDock-APP](https://github.com/evaldock/EvalDock-APP)。请在新库按 [Mac App 指南](https://github.com/evaldock/EvalDock-APP/blob/main/docs/MAC_APP.md)开发、启动和打包。

本仓库继续维护评测核心、Agent 适配器和高级工作台。完整客户端仓库内置后台源码 `engine/`，可独立构建、运行和打包；本库不再是它的构建时下载依赖。框架运行接口见 [客户端运行接口](CLIENT_RUNTIME.md)。历史公开安装包仍保留在原发布页；新客户端的构建与更新目标为 EvalDock-APP。
