# EvalDock v0.1

EvalDock 的首个 macOS 桌面正式版本，提供 Agent 接入、本地题库导入、评测执行、证据采集和 Judge 报告。

## 下载与安装

- `EvalDock-v0.1-macOS-arm64.dmg`：Apple Silicon Mac 安装包；不适用于 Intel Mac。
- 打开 DMG，将 EvalDock 拖到 Applications 后启动。
- 当前安装包未使用 Developer ID 签名，也未完成 Apple 公证；macOS 可能阻止首次打开。确认下载来源后，在系统设置「隐私与安全性」中允许打开。不需要关闭系统安全保护。
- 安装包内置应用运行时。被测 Agent、登录账号、Planner/Judge API 配置，以及题目所需的 Python、浏览器等依赖需自行准备。

## 首次使用

1. 在「设置」填写 Planner 和 Judge 接口及密钥。
2. 在「我的 Agent」扫描并接入本机 Agent；发现安装不代表接口、实际执行或评分已经验收通过。
3. 使用内置的一道合成文件交付演示题，或导入独立题库。
4. 开始评测，在「评测记录」查看实际进度和报告。

## 发布内容与数据边界

安装包只包含程序、必要运行依赖、公开配置模板和一道合成演示题。合成题的评分参考供本地服务端 Judge 使用，不作为真实题库分发。`environments/macos.json` 是公开运行契约，并非开发者机器的环境快照。

不包含个人配置、密钥、登录凭据、真实题库、评测历史、日志、报告、虚拟环境、Agent 安装文件或 Git 历史。发布源码使用独立快照；GitHub 自动提供的源码归档对应该快照。

用户配置、题库和结果保存在本机应用数据目录，模型密钥保存在用户独立配置中；不包含在发布附件中。升级保留用户数据。详细使用方式见 `docs/MAC_APP.md`。

`RUNTIME-FILES.json` 列出安装包运行资源的相对路径、大小和 SHA-256；`COMMIT.txt` 标识发布源码快照。下载附件后，可执行 `shasum -a 256 -c SHA256SUMS` 校验附件。

## 限制

- 本版只提供 Apple Silicon macOS 安装包，不承诺 Windows、Linux 或 Intel Mac 可运行。
- Agent 兼容性取决于本机版本、登录、模型和工具配置；自动化测试不能替代每一种真实 Agent 的完整评测验收。
- 没有自动更新、在线题库浏览和 ZIP 题库导入；完整题库按文件夹导入。
