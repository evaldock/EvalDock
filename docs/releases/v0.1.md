# EvalDock v0.1

EvalDock 是一款用于测试 AI Agent 的 Mac 应用。你可以选择任务，让已接入的 Agent 执行，然后查看执行记录、交付文件和模型评分报告。

## 下载与安装

本版适用于搭载 Apple M 系列芯片的 Mac，不支持 Intel Mac、Windows 或 Linux。

1. 下载 [EvalDock-v0.1-macOS-arm64.dmg](https://github.com/evaldock/EvalDock/releases/download/v0.1/EvalDock-v0.1-macOS-arm64.dmg)。只需下载这一个文件，下面的 Source code 是供开发者使用的源码，不需要下载。
2. 双击打开 DMG，将 EvalDock 拖到「Applications（应用程序）」文件夹。
3. 从「应用程序」中打开 EvalDock。

如果 macOS 阻止打开：本次更新修复了安装包签名完整性错误，但本版仍未使用 Apple 发行证书签名，也未完成公证。确认安装包来自本页面后，可前往「系统设置 → 隐私与安全性」，找到 EvalDock 的提示并选择「仍要打开」。无需关闭系统安全保护。

## 开始使用

1. 准备 Agent。先在电脑上安装并登录你要测试的 Agent。EvalDock 不附带这些 Agent，也不会替你安装或登录。
2. 配置评测模型。打开 EvalDock 的「设置」，填写模型名称、API 接口地址和 API Key。Planner 用于自动选题，Judge 用于评分。使用模型服务可能产生费用。
3. 接入 Agent。在「我的 Agent」中扫描本机安装，按页面提示接入并检查连接。发现 Agent 后，仍需完成连接和运行条件检查才能评测。
4. 选择题目。安装包内置一道演示题，用于熟悉流程；你也可以在「测试集」中导入自己的题库文件夹。演示题不用于能力排名。
5. 运行并查看结果。点击「开始评测」，选择 Agent 和题目。在「评测记录」中查看进度、执行记录和评分报告。

## 数据与题库

- 安装包不包含开发者的个人配置、账号密钥、历史评测记录或真实题库。
- 你自己的配置、题库和评测结果保存在本机，升级时保留。
- 导入题库会切换当前题库，旧题库会自动备份；目前不支持 ZIP 文件直接导入。

## 本版说明

- Agent 能否运行取决于它的版本、登录状态、模型配置和工具权限，请以应用中的检查结果为准。
- 某些任务需要额外安装 Python、浏览器或其他工具，具体取决于所用 Agent 和题目要求。
- 本版暂不支持自动更新或在线下载题库。

更多使用说明见 [Mac 应用使用指南](https://github.com/evaldock/EvalDock/blob/v0.1/docs/MAC_APP.md)。
